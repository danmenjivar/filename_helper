# filename_helper

A small browser utility to generate consistent monthly filenames.

Description
- Generates readable, consistent filenames for monthly documents.

Usage
- Open [index.html](index.html) in your browser.
- Use the UI to enter a month/year (or select options) and copy the generated filename.

Files
- [index.html](index.html) — app UI
- [script.js](script.js) — application logic
- [styles.css](styles.css) — styling

Development
- To run locally, open `index.html` in a browser.
